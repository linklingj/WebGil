# WebGil (웹길)

> 웹사이트를 구조적으로 재구성해, 시각장애인이 문서를 "훑어" 탐색하고 자연스러운 음성으로 듣는 오픈소스 스크린리더

WebGil은 웹페이지를 시각적 픽셀 순서가 아니라 **의미적 문서 트리**로 재구성한다. 사용자는 목차 수준의 최상위 레벨에서 시작해 관심 있는 항목만 계층적으로 파고들며, 트랙패드 제스처와 자연어 명령으로 조작하고, 최신 TTS로 듣는다.

## 핵심 기능

- **구조적 재구성** — DOM + 접근성 트리(AX Tree)를 병합해 계층적 문서 트리 생성
- **점자 훑기 내비게이션** — 트랙패드로 같은 레벨을 훑고, 스페이스로 하위 레벨 진입
- **자연스러운 TTS** — 로컬/API 음성, 스타일 선택
- **자연어 명령** — "로그인창 눌러줘" 같은 명령을 LLM이 요소 탐색·실행 (로컬/API)

## 아키텍처

셸 독립 코어 + `CaptureSource` 인터페이스. 페이지 접근 방식(확장/데스크톱/헤드리스)만 어댑터로 교체한다.

| 경로 | 역할 |
|---|---|
| `packages/core` | 셸 독립 코어 (구조추출·트리·TTS/LLM 추상화) |
| `apps/extension` | `ExtensionSource` — 브라우저 확장 (대회 MVP) |
| `apps/desktop` | `DesktopSource` — Electron 데스크톱 앱 (확장) |
| `tools/bench` | `PlaywrightSource` — 개발/벤치 하니스 |
